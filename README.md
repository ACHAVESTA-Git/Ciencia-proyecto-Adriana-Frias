# Germinación de la lenteja marrón bajo distintos colores de luz

Sitio estático (HTML + CSS, sin compilación) del proyecto de Ciencia y Tecnología.

## Estructura
- `index.html`: todo el contenido (secciones 1 a 8 y el proceso día a día).
- `styles.css`: estilos.
- `img/`: fotos optimizadas (`-mini` son las miniaturas).

## Publicar en Cloudflare Pages
1. Workers & Pages › Create › Pages › Connect to Git.
2. Elegir el repositorio `Ciencia-proyecto-Adriana-Frias`.
3. Framework preset: **None**. Build command: *(vacío)*. Build output directory: `/`.
4. Save and Deploy.
